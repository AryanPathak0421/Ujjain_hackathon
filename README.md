# 🚨 Stampede Prevention Dashboard

A real-time **crowd monitoring and risk detection dashboard** built with **React (Vite) + TailwindCSS**.  
The system provides **live camera feeds, crowd density alerts, PTZ (Pan-Tilt-Zoom) controls**, and **emergency broadcast actions** to help authorities prevent stampedes in crowded gatherings.

---

## ✨ Features
- 📹 **Live Camera Feeds** – Monitor multiple CCTV/IP cameras in real-time.
- ⚠️ **Automated Risk Alerts** – Get instant warnings for overcrowding or abnormal crowd behavior.
- 🎥 **PTZ Controls** – Pan, Tilt, and Zoom individual cameras via a modal interface.
- 📢 **Emergency Actions** – Trigger announcements, alerts, and evacuation protocols.
- 🎨 **Modern UI** – Built with **TailwindCSS** + **lucide-react** icons.

---

## 📦 Tech Stack
- **React 18** (via Vite)
- **TailwindCSS** (utility-first CSS)
- **lucide-react** (icons)
- **Vite** (fast dev + build tool)
